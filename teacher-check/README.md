# 教师检查材料

这是本仓库的教师验收入口。每个实验按编号分目录，老师可以直接打开对应的 `labN/`：

* `images/` 放运行截图和实验图示；
* `docs/` 放结果说明、原始输出和 Git 记录。

检查顺序建议：先看 `images/` 中带 `terminal` 或 `run` 的真实截图，再看 `docs/labN-build-and-test.txt` 和 `docs/labN-git-proof.txt`，最后查看代码与可编辑图源。

当前已完成：

* [Lab0](lab0/)
* [Lab1](lab1/)

后续实验必须在同一结构下新增 `labN/images/` 和 `labN/docs/`，并在根目录 README 的教师检查表中登记。

实验材料以各 Lab 目录中的 README 和文件名为准。
