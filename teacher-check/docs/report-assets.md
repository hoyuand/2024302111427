# Lab 报告证据索引

本目录按实验编号保存可复核证据，后续实验沿用同样布局：

* `teacher-check/labN/docs/labN-build-and-test.txt`：构建、官方/自写测试、运行结果。
* `teacher-check/labN/docs/labN-qemu-output.txt`：串口或功能输出的逐字节记录。
* `teacher-check/labN/docs/labN-git-proof.txt`：提交、标签、远端和推送状态。
* `teacher-check/labN/images/labN-*.png`：可插入实验报告的图片；需要修改时编辑同目录源文件。

Lab1 资产：

* [QEMU 输出与验收结果 PNG](../lab1/images/lab1-verification.png)
* [Git 提交与标签 PNG](../lab1/images/lab1-git-timeline.png)
* [构建与测试文字记录](../lab1/docs/lab1-build-and-test.txt)
* [串口逐字节记录](../lab1/docs/lab1-qemu-output.txt)
* [Git 归档记录](../lab1/docs/lab1-git-proof.txt)

每轮实验完成后，只需复制这四类文件并替换 `labN`，即可在期末报告中按实验编号汇总。
