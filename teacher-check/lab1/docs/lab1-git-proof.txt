Push verification
-----------------

  git ls-remote --heads --tags origin refs/heads/main refs/tags/lab1
The two remote object IDs must be equal; the GitHub remote then contains the same commit
as the local `main` branch and `lab1` tag. The commands intentionally resolve the final
commit after each archive update, so this note remains valid when the repository grows.
