# 教师验收材料

本目录集中放置各实验的验收重点。每个 Lab 使用相同的结构：

* `images/`：真实终端运行截图和实验图示；展示图片统一使用 PNG；
* `docs/`：实验结果摘要、原始输出、设计说明和 Git 归档记录。

目录名 `doc/` 与新版实验说明书要求的 `doc/lab0/` 路径保持一致；这里同时承担教师验收和实验报告素材归档作用。
